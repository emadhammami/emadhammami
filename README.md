## Selected research software

**[R3Tune — stage-aware LLM token budgeting](https://github.com/emadhammami/stage-aware-llm-resource-allocation)**  
A 4,000-run study across three open-weight model families. The primary comparison met a pre-specified non-inferiority criterion for reliable correctness; it did not demonstrate material token savings.

**[Evidence-Gated code repair](https://github.com/emadhammami/evidence-gated-budget-aware-code-repair)**  
An empirical study of how executable test results can guide verification and recovery in multi-stage LLM workflows. The repository includes a 240-run QuixBugs evaluation artifact.

**[uAMBIT — federated update compression](https://github.com/emadhammami/uambit-hard-cap-fl)**  
Research on uplink communication budgets in federated learning. The published paper evaluates MNIST, BreastMNIST, CIFAR-10, and electricity-load forecasting; the public repository contains a BreastMNIST demonstration and accompanying code rather than every experiment from the paper.

**[Responsible Agentic Workflows](https://github.com/emadhammami/responsible-agentic-workflows)**  
Ongoing USN master's research on the reliability, task quality, latency, and resource use of LLM-based agentic workflows with and without guardrails.

**[LangGraph Budget-Aware Code Agent](https://github.com/emadhammami/langgraph-budget-aware-code-agent)**  
An academic prototype using Planner–Executor–Critic steps, executable validation, and structured telemetry.

**[Weather and traffic accidents in Oslo and Akershus](https://github.com/emadhammami/oslo-akershus-weather-traffic-accidents)**  
USN MIS404 group coursework: descriptive analysis and predictive comparisons using monthly accident and weather observations from 2014–2024. The repository includes recorded results and figures.

## Earlier experimental work

I also maintain four historical federated LSTM compression prototypes: [baseline](https://github.com/emadhammami/Compressed-Federated-Time-Series-Forecasting), [univariate](https://github.com/emadhammami/Compressed-FL-Univariate-LSTM-Forecasting), [multivariate](https://github.com/emadhammami/Fed-Multivariate-LSTM-DeltaComp), and [byte-budgeted](https://github.com/emadhammami/fed-lstm-budgeted-compression). Their temporal data construction requires revalidation; the reported forecasting errors should not be treated as validated benchmarks. These repositories should not be assumed to reproduce the published uAMBIT electricity experiments.
